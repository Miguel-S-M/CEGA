SIMULADORES CONECTADOS — 27/07/1945

Abra index.html para o simulador de decisão sobre alternativas à invasão/bomba. No canto superior há um botão para abrir o simulador nuclear. No simulador nuclear, use o botão no canto superior direito para voltar ao simulador de decisão.

Mantenha index.html, nuclear.html, style.css e script.js na mesma pasta. Abra index.html no navegador. O mapa do simulador nuclear usa bibliotecas e dados geográficos carregados pela internet.
